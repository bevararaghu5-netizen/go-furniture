# Screenshot checklist

Save real screenshots from your own Go Furniture project here:

- `01-home-page.png` — homepage in the browser.
- `02-products-visible.png` — product cards visible on the deployed site.
- `03-kubernetes-pods.png` — `kubectl get pods` showing the relevant pods Ready.
- `04-kubernetes-services.png` — `kubectl get services`.
- `05-database-products.png` — sample product rows from PostgreSQL.

You can add further screenshots for the backend API response, Docker images, or Minikube service URL if useful. Before committing screenshots, remove credentials, tokens, personal information, and sensitive logs.
